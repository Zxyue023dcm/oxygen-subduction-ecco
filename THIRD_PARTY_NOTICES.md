# Third-party components

This repository bundles third-party MATLAB components needed by the calculation and figure scripts. These components remain under their own authorship and terms.

- `function/gsw_matlab_v3_06_16_1/`: GSW Oceanographic Toolbox. The supplied license is retained in `html/gsw_licence.html` and `pdf/gsw_licence.pdf`.
- `function/m_map/`: M_Map mapping package. The supplied package documentation is retained in that directory.
- `function/boxplot_custom.m`: MathWorks File Exchange contribution. The accompanying notice is retained as `function/boxplot_custom_license.txt`.
